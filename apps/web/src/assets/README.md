Geist social-preview font is the Latin variable font from the installed
`@fontsource-variable/geist` package, converted from WOFF2 to TTF with FontTools
without changing glyphs or names, and base64 encoded for a server-only Vite raw
import. Its SIL Open Font License is included as `Geist-OFL.txt`.

The font and native PNG renderer are imported only by `.server.ts` modules.
Profile preview images use published name, handle and headline; no remote avatar
is fetched and no proof verification or organization-review badge is invented.
