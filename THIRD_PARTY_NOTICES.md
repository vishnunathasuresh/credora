# Third-party component notices

Credora adapts the following component patterns from [OpenSource UI](https://opensourceui.in/components):

- **Copy to Clipboard** — the copied confirmation and timed reset in `apps/web/src/components/ui/opensource-ui-copy-button.tsx`. The share flows keep their own clipboard fallback and error handling.
- **Editorial Staff Profile** — the compact identity row in `apps/web/src/components/profile/editorial-profile-identity.tsx`, adapted for Credora's illustrative profile data and without a roster index or remote image.

The source pages provide React component code and state that components are MIT licensed, free for personal and commercial use, and require this copyright and permission notice when code is copied. Credora's adaptations are identified in their source files.
